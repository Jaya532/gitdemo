LINUX COMMANDS HANDBOOK
Commands, Uses, Examples, and Sample Outputs
For Linux / DevOps Fresher Training

IMPORTANT NOTES
- Sample outputs are examples. Your output can differ by Linux distribution, permissions, installed packages, and machine state.
- Commands marked with sudo require suitable sudo privileges.
- Practice on a test EC2 instance, not a production server.
- Be careful with commands that delete files, change permissions, restart services, or modify configuration.
- Amazon Linux 2023 examples use dnf. Ubuntu examples usually use apt.
- Replace placeholders such as <EC2-PUBLIC-IP>, <PID>, and <service> with real values.
- Some examples use sample files created below.

============================================================
1. BASIC SYSTEM AND NAVIGATION COMMANDS
============================================================

1. pwd

Use: Prints the current working directory.

Command:
  pwd
Sample output:
  /home/ec2-user

2. whoami
Use: Shows the current username.
Command:
  whoami
Sample output:
  ec2-user


3. id
Use: Shows user ID, primary group, and supplementary groups.
Command:
  id
Sample output:
  uid=1000(ec2-user) gid=1000(ec2-user) groups=1000(ec2-user),10(wheel)


4. hostname
Use: Prints the system hostname.
Command:
  hostname
Sample output:
  ip-10-0-1-25

5. hostnamectl

  hostnamectl
Sample output:

Use: Shows kernel and system information.

  cat /etc/os-release
Sample output:

Use: Shows how long the system has been running, logged-in users, and load averages.

Use: Shows the current date and time.

  clear

4. AWK COMMAND
============================================================

awk processes text line by line and is often used to select columns and filter data.

employee.txt file data : 
Rajesh DevOps 100000
Sarma Linux 80000
Ravi AWS 90000


43. Print first column
Command:
  awk '{print $1}' employees.txt
Use: Prints the first whitespace-separated field.
Sample output:
  Rajesh
  Sarma
  Ravi

44. Print second and third columns
Command:
  awk '{print $2, $3}' employees.txt
Use: Extracts selected columns.
Sample output:
  DevOps 100000
  Linux 80000
  AWS 90000

45. Filter rows by a numeric condition
Command:
  awk '$3 > 85000 {print $1, $3}' employees.txt
Use: Prints employees whose third field is greater than 85000.
Sample output:
  Rajesh 100000
  Ravi 90000

46. Print the last field
Command:
  awk '{print $NF}' employees.txt
Use: $NF means the last field on the current line.
Sample output:
  100000
  80000
  90000

47. Count lines
Command:
  awk 'END {print NR}' employees.txt
Use: NR is the current record/line number.
Sample output:
  3

48. Extract filesystem and usage percentage
Command:
  df -h | awk 'NR > 1 {print $1, $5}'
Use: Skips the header and prints filesystem and usage percentage.
Sample output:
  devtmpfs 0%
  /dev/nvme0n1p1 23%
Note: Actual values vary by machine.

5. SED COMMAND
============================================================

sed is a stream editor used to substitute, print, or delete text.
employee.txt : 
Rajesh DevOps 100000
Sarma Linux 80000
Ravi AWS 90000



49. Replace first occurrence on each line (display only)
Command:
  sed 's/Sarma/Rajesh/' employees.txt
Use: Replaces the first Sarma occurrence on each line in output; original file stays unchanged.
Sample output:
  Rajesh DevOps 100000
  Rajesh Linux 80000
  Ravi AWS 90000

50. Replace all occurrences on each line
Command:
  echo 'error error error' | sed 's/error/issue/g'
Use: g means replace every match on each line.
Sample output:
  issue issue issue

51. Delete line 2 from output
Command:
  sed '2d' employees.txt
Use: Displays all lines except line 2; does not edit the original file.
Sample output:
  Rajesh DevOps 100000
  Ravi AWS 90000

52. Print only line 2
Command:
  sed -n '2p' employees.txt
Use: -n suppresses normal output; p prints the selected line.
Sample output:
  Sarma Linux 80000

53. Replace text in a file permanently (make a backup first)
Command:
  cp employees.txt employees.txt.bak
  sed -i 's/Sarma/Rajesh/' employees.txt
  grep 'Rajesh' employees.txt
Use: -i edits the file in place.
Sample output:
  Rajesh DevOps 100000
  Rajesh Linux 80000
Caution: This changes the original file. Restore with:
  cp employees.txt.bak employees.txt

13. NGINX DEPLOYMENT: Sarma.html
============================================================

Goal: Install Nginx, create Sarma.html, and access it from a browser.

Step 1: Install Nginx (Amazon Linux 2023)
  sudo dnf install nginx -y

Step 2: Start and enable it
  sudo systemctl enable --now nginx

Step 3: Verify service
  sudo systemctl status nginx
Expected:
  Active: active (running)

Step 4: Validate configuration
  sudo nginx -t
Expected:
  nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
  nginx: configuration file /etc/nginx/nginx.conf test is successful

Step 5: Create the HTML page

Step 7: Test locally

Step 8: Check listener

Expected:

Step 9: Allow inbound HTTP in the EC2 Security Group
  Add inbound rule: HTTP, TCP, port 80, source 0.0.0.0/0 for a temporary public training page.
  For production, restrict access as appropriate. Ensure the instance has a public IP and a route through an Internet Gateway if it is in a public subnet.

Step 10: Open from your computer browser
  http://<EC2-PUBLIC-IP>/Sarma.html

Troubleshooting if Nginx is inactive or failed:
  sudo nginx -t

  sudo journalctl -u nginx -n 50 --no-pager
  sudo ss -lntp | grep :80

  - OS firewall, if configured

14. USEFUL PIPES AND REDIRECTION
============================================================

116. Pipe |
Use: Sends output from one command to another command.
Command:
  ps -ef | grep nginx
Sample output:
  root 900 1 0 10:00 ? 00:00:00 nginx: master process

117. Output redirection >
Use: Writes output to a file, replacing existing contents.
Command:
  echo 'Hello Linux' > output.txt
  cat output.txt
Sample output:
  Hello Linux

118. Append redirection >>
Use: Adds output to the end of a file.
Command:
  echo 'Second line' >> output.txt
  cat output.txt
Sample output:
  Hello Linux
  Second line

119. Standard error redirection 2>
Use: Writes error messages to a separate file.
Command:
  ls /missing-path 2> errors.txt
  cat errors.txt
Sample output:
  ls: cannot access '/missing-path': No such file or directory

120. tee
Use: Displays output and writes it to a file at the same time.
Command:
  echo 'deployment started' | tee deploy.log
Sample output:
  deployment started

15. REAL-WORLD TROUBLESHOOTING CHECKLIST
============================================================

SCENARIO A: Nginx website is down
1. Check instance status in AWS console.
2. Check service:
     sudo systemctl status nginx
3. Check configuration:
     sudo nginx -t
4. Check logs:
     sudo journalctl -u nginx -n 50 --no-pager
5. Check port:
     sudo ss -lntp | grep :80
6. Test locally:
     curl -I http://localhost/Sarma.html
7. If local test works but external access fails, check Security Group, route, public IP, NACL, and firewall.

SCENARIO B: Disk usage is high
1. Check filesystems:
     df -h
2. Check inodes:
     df -i
3. Find large directories:
     sudo du -sh /var/*
4. Find large files:
     sudo find /var -type f -size +500M -exec ls -lh {} \\;
5. Check deleted-but-open files:
     sudo lsof +L1
Do not delete logs blindly; confirm ownership, retention, and impact first.

SCENARIO C: CPU usage is high
1. Run:
     top
2. Identify top CPU processes:
     ps aux --sort=-%cpu | head
3. Check logs and recent changes.
4. Confirm with the application owner before terminating production processes.

SCENARIO D: Memory usage is high
1. Run:
     free -m
2. Identify processes:
     ps aux --sort=-%mem | head
3. Investigate application behavior, logs, and workload before restarting or killing anything.

SCENARIO E: Port 8080 is unreachable
1. Check listener:
     sudo ss -lntp | grep :8080
2. Test locally:
     curl -v http://localhost:8080
3. If no listener exists, check whether the application is running and configured for port 8080.
4. If local curl works but remote access fails, check the app bind address, OS firewall, Security Group, NACL, route, and load balancer.

SCENARIO F: DNS problem
1. Test IP connectivity:
     ping -c 4 8.8.8.8
2. Test DNS:
     nslookup example.com
     dig example.com
3. Review:
     cat /etc/resolv.conf
A blocked ping alone does not prove internet connectivity is broken; ICMP can be filtered.

SCENARIO G: SSH connection fails
1. Confirm instance is running and the IP/key/username are correct.
2. Check sshd:
     sudo systemctl status sshd
3. Check port:
     sudo ss -lntp | grep :22
4. Check AWS Security Group inbound TCP/22 from the required trusted source.
5. Review route, NACL, network connectivity, and:
     sudo journalctl -u sshd -n 50 --no-pager
Never expose SSH to the whole internet unless there is a justified, controlled need; prefer a trusted IP, VPN, or managed access service.

16. QUICK INTERVIEW DEFINITIONS
============================================================

pwd      - Prints the current working directory.
ls       - Lists files and directories.
grep     - Searches text using a pattern.
find     - Finds files/directories by criteria.
awk      - Extracts and processes fields/records in text.
sed      - Substitutes, prints, or deletes text from streams/files.
curl     - Sends URL requests and tests HTTP/HTTPS endpoints.
df -h    - Shows filesystem capacity and usage.
du -sh   - Shows the size of a file/directory.
free -m  - Shows memory and swap usage.
top      - Displays live system and process statistics.
ps -ef   - Lists processes.
ss       - Shows sockets and listening ports.
systemctl - Manages systemd services.
journalctl - Reads the systemd journal.
chmod    - Changes permissions.
chown    - Changes ownership.
tail -f  - Follows new log lines.
lsof     - Lists open files.
ip addr  - Shows interfaces and IP addresses.
ip route - Shows the routing table.
nslookup/dig - Troubleshoot DNS resolution.
